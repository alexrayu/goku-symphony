## Gotchas
- Composer's global GitHub token is stale (Flex 404s): clean `COMPOSER_HOME` (`-e COMPOSER_HOME=/tmp/ch`), quote constraints in zsh. `doctrine-bundle` pulls Symfony 8.x: keep all `symfony/*` at 7.4, recheck the lock. Don't set `config.platform.php` below the container's PHP patch. Container PHP is 8.4: no pipe operator.
- `csrf.yaml`: only `submit` is stateless (stateless tokens need the Stimulus csrf controller). Login, logout and custom admin forms use session token ids.
- Installer subscriber at priority 64: the router (32) would 404 `/` first, the firewall (8) would send `/admin` to `/login`.
- Tests: public pages need a user in the DB or redirect to `/install`. `cache:clear` does not clear cache.app (`cache:pool:clear cache.app`); test env uses the array cache. Flysystem is autowired by name (`$defaultStorage`); tests fetch `'default.storage'`, write to `var/storage-test`. Foundry 2 returns real entities; factories don't fill inverse sides (`Work::$chapters`): clear the EM and reload. Multi-request tests with in-memory transport or array-cached settings need `disableReboot()`.
- Query counting: no web-profiler bundle; tests `enableProfiler()`. Reset `doctrine.debug_data_holder` and clear the EM before the counted request. Series reader = 5 in tests (install check + site settings are array-cached there, cached in dev/prod).
- PHPStan remembers getter results across setter calls on the same object; use separate instances in tests.
- EasyAdmin detail rows never shrink below their content: a wide custom field (table) widens the whole field grid on phones and clips every value. Wrap it in `.table-responsive` with `style="width: 0; min-width: 100%"` (style attrs pass the CSP). DB unique keys need a matching `UniqueEntity`, else EA forms 500 on duplicates.
- EasyAdmin: `NumberField` on DECIMAL needs `setStoredAsString()` + `setNumberFormat()`. `formatValue()` strings render raw: never return user text. Blank nulls via the dashboard `label/null` override. `/admin` -> 302 `/admin/work`. Save button labels: "Save changes" / "Save and continue editing" (the settings page has only the latter).
- Flysystem modes need YAML octal `0o750` + `visibility: public`. Dev as root hid it.
- Calling `getUser()` on the lazy firewall touches the session for anonymous visitors and makes responses private (killed edge caching once): check `hasPreviousSession()` first (`ReaderController::previewsDrafts()`).
- `.css.twig` autoescapes with the CSS strategy: `#ff6a4d` became `\23 ff6a4d`. `SiteSettings::getAccent()` always returns valid hex; templates print it `|raw`.
- `VIPS_BLOCK_UNTRUSTED=1` also blocks `vipsload`/`matload`, used by the scramble pipeline's own intermediates: only on calls reading uploads. Dev libvips has `magickload`.
- CSP: browsers merge a 304's headers into the cached page, so `SecurityHeaders` (priority 16) must hash the full body before `PublicPageCache` (0) makes the 304. `Content-Type` is unset during kernel.response; missing = HTML. `BinaryFileResponse::prepare()` returns early for 304 (no X-Accel, no body).
- Image-quality checks: gradients and colour in the real browser; text on white hid tile seams.
- Harness only: the host's php-fpm AppArmor profile attaches inside privileged containers (FPM runs from a copied binary via drop-in); Ubuntu images block service start (policy-rc.d) and lack sudo. FPM socket stays `php8.4-fpm.sock`. Ondrej PPA via `deb822_repository`.

## Decisions
- Stack per CLAUDE.md. Added, user-approved: `symfony/test-pack`, `phpstan-symfony`, `phpstan-phpunit`, `symfony/rate-limiter`, `symfony/process`. `symfony/clock` is only transitive: making it direct needs approval (entities use `new \DateTimeImmutable()`).
- Prod: Ubuntu 24.04, PHP 8.4 (ondrej), PG 16, Redis 7; deploy = git clone of `alexrayu/goku-symphony` into releases/ + symlink; secrets in untracked `ansible/secrets.yml`. Cloudflare Free caps bodies at 100 MB; origin upload limit 200M.
- Installer (approved override): open form, first user only; `UserProvisioner` is the one user-creation path. Close the window by creating the user over SSH before DNS (README).
- Domain: `Chapter.number` NUMERIC(6,1), `getNumberLabel()` drops ".0". Oneshot rule via `Assert\Callback` on Chapter and Work. `Chapter.publishedAt` = first publication only (no setter; tests use reflection), `isNew()` within 7 days. Optional `Chapter.summary` (reader header + meta description). `direction` stored, hidden in admin.
- Ingest: libvips CLI. One scrambled WebP per page (128 px tiles + 8 px gutter = 144 px cells, `mapim` with a .mat index), max 1200 wide, Q80, never upscaled, reading height cap 14464. Plus per chapter a 1200x630 JPEG og cover and a 400x560 WebP thumb from page 1 (approved exception to "no extra sizes"). Caps: 64 MB per entry, 1000 images, 2 GB total. Generated keys only. Final failure sets page `failed`.
- Reader: Stimulus controller rebuilds tiles on canvas (segments <= 4096 px, iOS), loads/unloads by IntersectionObserver, blocks contextmenu/drag/select. Arrow keys = prev/next chapter. CSS scroll-timeline progress bar. importmap only on reader pages. Draft preview for logged-in users (private, noindex).
- URLs: `/{slug}` (oneshot reader in place), `/{slug}/chapter-{n}` (oneshot chapter URL 301s to `/{slug}`), `/about`; reserved slugs validated. All image URLs from `PageImageUrlGenerator` Twig functions.
- Media: PHP checks publication per request (one PK query), body via X-Accel-Redirect. Published: browser max-age (1y immutable for pages and versioned work cover/logo URLs, 1 day for chapter cover/thumb) + edge `s-maxage=3600` + Last-Modified 304, so unpublishing leaves the edge within the hour (user chose this over a purge API). Drafts `private, no-store`. A work cover is public once any chapter is published.
- DB DSN (2026-10-08, load test on phase-6 capped at 1 vCPU/1 GB): Unix socket + peer auth + `persistent=1`. TCP + SCRAM opened one PG session per request: 80-90 rps; socket alone ~140; socket + persistent ~330-500, p50 4-8 ms, ~80 MB anon. CPU-bound, memory fine for traffic. Ingest peak memory under 1 GB not yet measured (libvips was the reason for 2 GB). `db_password` now unused by the app (role keeps it). Harness: `~/Documents/tickets/goku-symfony/load-test/` (send `Host: goku.test:8443`, else absolute URLs and ETags differ). `phase-6/e2e.py` is stale (old `/w/` URLs, fixed ids).
- Caching: anonymous public HTML `public, s-maxage=300` + ETag (`PublicPageCache`); session responses private.
- Security: `SecurityHeaders` listener sets nosniff, Referrer-Policy, X-Frame-Options, HSTS (HTTPS only) and a hash-based CSP (user chose hashes over nonces to keep ETag/edge caching). Logout needs CSRF. Login throttled.
